# Локальное распознавание рукописи

Собственная часть приложения — выделение и поворот области, подготовка изображения,
разделение строк, CTC-декодер, выбор близких вариантов и проверка результата.
Веса PP-OCRv6 Medium Cyrillic открытые и предобученные; собственное обучение весов
в этом проекте пока не проводилось. Источники и лицензии — в `assets/handwriting/`.
Распознавание выполняется локально, без платного API.

Общий русский словарь выбирает только уже существующий близкий вариант CTC.
Он не меняет цифры, латинские коды и старую орфографию. Исходное чтение остаётся
в вариантах. Сохранённые пользователем названия — отдельный личный словарь.
Кнопка сохранения примера записывает подтверждённый фрагмент в IndexedDB;
это не обучение нейросети во время работы сайта.

## Проверки

Из корня проекта:

```powershell
node --test tools/handwriting/test_decoder.cjs
python -m unittest discover -s tools/handwriting -p test_prepare_training_data.py
```

Для оценки реальных изображений служит `evaluate_browser.cjs`. Он запускает
локальную модель в чистом профиле Edge, блокирует внешние запросы и запросы
не методом GET. Фотографии передаются в локальный canvas. Ручные расшифровки
остаются в Node и используются только для подсчёта ошибок после распознавания.
Нужен установленный отдельно `playwright-core`; путь к нему передаётся аргументом.

```powershell
node tools/handwriting/evaluate_browser.cjs --manifest C:/samples/manifest.json --playwright C:/tools/node_modules/playwright-core --output C:/samples/result.json
```

Формат манифеста: массив записей либо объект с полем `samples`. Каждая запись:

```json
{"id":"sample-1","file":"C:/samples/line.png","text":"Ручная расшифровка","kind":"modern-word","rotate":0,"box":[10,20,300,40],"mode":"text","singleLine":true}
```

`rotate` — поворот против часовой стрелки; необязательный `box` задаётся в пикселях
после этого поворота. `kind` — группа отчёта; `mode` — `text`, `code` или `auto`.
Для целого столбца задайте `singleLine:false`. Нормализация оценки меняет только
регистр и последовательности пробелов; буквы е/ё, старые буквы и цифры различаются.
CER — число вставок, удалений и замен, делённое на длину эталонного текста.

Выборочная проверка 24.11.2026: на трёх строках пользовательских фото точное
чтение выросло с 1 до 2; на 16 словах из школьных тетрадей — с 7 до 8.
На 22 строках Digital Peter точных чтений нет. Эти небольшие наборы показывают
конкретные ошибки, а не гарантируют точность на любом почерке. Полные таблицы
и источники сохранены в локальном отчёте проверки. Фотографии в репозиторий
не включаются.

## Подготовка подтверждённых примеров

```powershell
python tools/handwriting/prepare_training_data.py --input C:/samples/handwriting-examples.json
```

Команда создаёт данные в `handwriting-data/`, исключённой из Git. Фрагменты одной
фотографии и одинаковые изображения группируются, чтобы не смешивать обучение
и проверку. Команда не обучает модель. Проверочные документы следует держать
отдельно от обучающих и не добавлять их расшифровки в словарь ради оценки.
